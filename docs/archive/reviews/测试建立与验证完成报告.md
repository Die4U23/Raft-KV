### 快速运行（推荐）

```bash

```

### 手动运行

```bash
# 配置
mkdir -p build-test && cd build-test
cmake -S .. -B . -DRAFTKV_BUILD_SERVER=OFF -DCMAKE_BUILD_TYPE=Debug

# 编译
cmake --build . --target replication_logic_tests connection_order_tests

# 运行
./tests/replication_logic_tests
./tests/connection_order_tests

# 或使用 CTest
ctest -R "replication|connection" --output-on-failure
```

### 集成到现有工作流

```bash
# 所有可移植测试（包含新测试）
cmake -S . -B build-portable -DRAFTKV_BUILD_SERVER=OFF
cmake --build build-portable
ctest --test-dir build-portable --output-on-failure

# 完整测试（Linux）
python3 scripts/build_linux.py --jobs 2 --smoke
```
