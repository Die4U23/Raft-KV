# 新增测试说明

## 测试文件

本次为 security-fixes-phase1 分支添加了两个新的测试文件：

### 1. replication_logic_tests.cpp

**目的**: 验证 Raft 复制确认逻辑的正确性

**测试内容**:
- ✅ 基本的 matchIndex 更新
- ✅ matchIndex 不应倒退
- ✅ 过期 RPC ID 应被拒绝
- ✅ 响应的 matched 位置验证
- ✅ 多数派确认推进 commitIndex
- ✅ 单个在途请求限制
- ✅ 不同步的副本处理

**运行方式**:
```bash
./scripts/run_new_tests.sh
# 或者
cmake --build build-new-tests
./build-new-tests/tests/replication_logic_tests
```

**验证的关键属性**:
1. **matchIndex 单调性** - 一旦前进就不会倒退
2. **RPC ID 验证** - 防止过期响应导致错误
3. **位置一致性** - 响应的位置必须与请求对应
4. **多数派语义** - commitIndex 只在多数派确认后推进
5. **在途控制** - 每个 peer 只允许一个在途请求

### 2. connection_order_tests.cpp

**目的**: 记录同连接命令顺序的当前限制

**测试内容**:
- ⚠️ SET 后立即 GET 在同一连接上（当前不保证顺序）
- ⚠️ SET 后 PING 在同一连接上（响应可能乱序）
- ⚠️ 多个 SET 在同一连接上（执行顺序正确，响应可能乱序）
- ⚠️ Pipeline 模式下的命令顺序
- ⚠️ 失去多数派后的命令积压
- ⚠️ 断开连接时的待处理请求
- 💡 建议的改进方案（每连接命令队列）

**运行方式**:
```bash
./scripts/run_new_tests.sh
# 或者
./build-new-tests/tests/connection_order_tests
```

**说明**:
这是一个**文档性测试**，用于：
1. 明确记录当前的限制
2. 提供改进方案的示例代码
3. 为中期改进项目提供验收标准

## 测试分类

### 可移植测试（不依赖 Muduo/RocksDB）
- `protocol_tests.cpp` - RESP 协议和 Raft 编码

- `storage_batch_tests.cpp` - 存储批量操作

## 集成到 CI

add_executable(connection_order_tests connection_order_tests.cpp)
add_test(NAME connection_order_tests COMMAND connection_order_tests)
