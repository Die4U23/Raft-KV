- Python 集成测试（分区、重启、过载）

✅ **已验证场景**
| 场景 | 结果 | 证据文档 |

| 崩溃重启 | 1,704 键保留 | write-restart-validation.md |
| 过载保护 | 连接准入、BUSY、资源阈值 | overload-validation.md |

### 3.2 性能基线

**环境**: 双核 VM，三节点同机，32 连接，pipeline=1，128B value，50% GET/SET

| 模式 | 吞吐量 | P50 延迟 | P99 延迟 |
|------|--------|----------|----------|
| 同步应用 | 3,656 ops/s | 7.88-8.85 ms | 20.61-25.67 ms |
| 异步应用 | 3,825 ops/s | 8.05-8.35 ms | 18.39-26.89 ms |

### 3.3 已知限制

⚠️ **明确的边界**（README.md 已标注）
- GET 是本地读，不保证线性一致性
- 固定成员单 Raft 组，无动态变更
- 无快照与日志压缩
- 无客户端请求去重
- 同连接命令可能乱序执行
